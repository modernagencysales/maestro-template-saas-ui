## Durable resources

`modelCallReceipts` stores tenant, attempt, provider/model/region, state,
instruction/tool/schema/policy/lifecycle generations, redaction state, canonical
request/response/source hashes, usage, cost, latency, and creation time. It is
indexed for tenant/state, attempt uniqueness, generation, hash, and provider
lookups. The provider-neutral structured gateway validates immutable content
bytes and hashes, output schema, model-egress policy, and echoed receipt
identity before returning decoded output.

## Lifecycle behavior

Receipt state is
`queued -> running -> succeeded | retryable_failure | permanent_failure | cancelled`.
Tenant and lifecycle generation are bound to each append; duplicate
tenant/attempt writes and wrong organization, workspace, or generation fail
closed. Durable rows retain hashes and accounting metadata, never raw prompts or
completions.

## Compatibility and rollback

Fake/local transport remains the default. Live mode without an explicitly
provided transport returns a typed policy denial, so no provider call is
silently substituted. Rollback disables the structured-model callers, keeps
append-only receipts for audit, and restores the last admitted model/policy
generation without deleting evidence.
