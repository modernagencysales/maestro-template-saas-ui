# S09-T01 Lifecycle Adoption Record

**Owner:** S09-T01  
**State:** integrated; acceptance pending S07 and S08

## Durable resources

S09-T01 adds no durable table. It replaces the synchronous search API with an
Effect `AsyncSearchService`, a provider-neutral live `SearchProvider`, typed
input/cursor/timeout/provider failures, and tenant-scoped candidate records.

## Lifecycle behavior

Every request validates workspace, Brain, query, result cap, and cursor before
provider execution. Live calls are asynchronous and cancellable and fail with a
typed timeout or provider error. Deterministic ordering and the bounded result
cap keep retrieval input stable for downstream lifecycle-fenced context reads.

## Compatibility and rollback

Product runtime uses provider-neutral async adapters. Rollback uses the async
test provider rather than the removed synchronous token-overlap API. The
deterministic token-overlap scorer is scoped to test/rollback wiring only and is
not a public production mode.
