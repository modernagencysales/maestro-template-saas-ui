# S02-T01 Lifecycle Adoption Record

**Owner:** S02-T01  
**State:** integrated; acceptance pending S01 completion

## Durable resources

`brainPages` retains its legacy workspace, slug, Markdown, and editor fields and
adds optional stable page identity, parent/sibling ordering, favorite/status,
current revision, lifecycle envelope, creation time, and schema version fields.
`pageRevisions` is the append-only revision resource, indexed by tenant-scoped
revision key, page/time, page/content hash, and idempotent effect key.

## Lifecycle behavior

Pages carry `active | archived | redacted | purged`; revisions carry an
independent `active | redacted | purged` envelope and a generation fence. Graph
validation rejects duplicate tenant page/revision keys, duplicate active sibling
slugs, cross-Brain parents or current revisions, and page cycles. Public page
summaries expose stable keys and lifecycle generation without Convex or
organization identifiers.

## Compatibility and rollback

The stable-identity fields on existing `brainPages` rows are optional during
schema expansion, so legacy readers remain valid while the S00-T04 migration
coordinator owns backfill and verification. Rollback keeps the additive fields
and returns readers to the legacy slug/Markdown shape; it does not delete
revisions or run a destructive reverse migration.
