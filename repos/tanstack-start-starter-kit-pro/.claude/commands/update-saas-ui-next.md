description: Update saas-ui packages to latest next versions and reinstall dependencies
---

Update all @saas-ui packages in to their latest next tag versions by:

1. Check latest next versions for these packages:
   - @saas-ui/core@next
   - @saas-ui/react@next
   - @saas-ui/forms@next
   - @saas-ui/modals@next
   - @saas-ui/hooks@next
   - @saas-ui-pro/react@next

2. Update the `pnpm.overrides config in the root package.json with the latest versions

3. Run `pnpm install` to update dependencies

Be concise in your output.
