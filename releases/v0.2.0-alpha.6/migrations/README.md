# v0.2.0-alpha.5 to v0.2.0-alpha.6 migration notes

This release advances the generated customer UI to the complete pinned Saas UI
Starter shell. It does not change durable data and does not require a data
migration.

Rollback uses the required pre-upgrade Git commit or the immutable alpha.5 tag.
Existing customer data and table names are unchanged, so no data rollback
receipt is required.
